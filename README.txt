# RP LOCAÇÕES — Site

Arquivos:
- index.html — página principal
- style.css — identidade visual e responsividade
- script.js — produtos, carrinho, localStorage e envio para WhatsApp

## Como usar
1. Abra o arquivo `index.html` no navegador.
2. Para publicar, envie os três arquivos para sua hospedagem.
3. O número usado no WhatsApp é 55 79 99178-8586.
4. O carrinho fica salvo no navegador usando localStorage.

## Preços configurados
- Jogo de mesa: R$ 10,00 por unidade, mínimo de 6 jogos
- Mesa avulsa: R$ 5,00
- Cadeira: R$ 3,00
- Tampão: R$ 7,00
- Toalha de mesa: R$ 6,00
- Toalha de tampão: R$ 7,00

Observação: o site trata o valor como estimativa e pede confirmação de disponibilidade pelo WhatsApp.
